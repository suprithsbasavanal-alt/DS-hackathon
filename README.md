# BreatheWise

**Air Quality & Weather Intelligence**\
Data Science Track --- DS05

## What it aims to do

BreatheWise is a Bengaluru-focused environmental analytics project. It
aims to explore real air-quality observations, visualize pollutant
patterns, analyze weather associations, identify unusual periods, and
provide explainable short-term PM2.5 forecasts if the validated dataset
supports them.

## Project status

Pre-implementation planning. The project concept is approved, but actual
dataset inspection and remaining organizer submission checks are
pending. Do not treat this repository as an implemented product until
working code is added and tested.

    https://data.opencity.in/dataset/bengaluru-hourly-air-quality-reports
-   Peenya CPCB 2024--25 CSV resource:
    https://data.opencity.in/dataset/bengaluru-hourly-air-quality-reports/resource/c6b4282e-43c8-4f14-a855-83e4b52a80d7

-   OpenAQ API: https://docs.openaq.org/api

    https://open-meteo.com/en/docs/historical-weather-api

## Data and health disclaimer

Do not treat BreatheWise as an official monitoring service or medical
advice. Distinguish observed readings, reanalysis, modelled estimates
and forecasts. AQI must be calculated using the applicable official
methodology and data requirements.
